# homebrew-tap

Homebrew tap for qjoly's tools.

## How to use

To add this tap to your Homebrew installation:

```bash
brew tap qjoly/tap
```

## Available Formulae

| Formula | Description | Install |
| --- | --- | --- |
| `talosctl-oidc` | OIDC certificate exchange server and client for Talos Linux | `brew install qjoly/tap/talosctl-oidc` |
