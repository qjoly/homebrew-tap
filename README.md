# homebrew-tap

Homebrew tap for qjoly's tools.

## How to use

```bash
brew tap qjoly/tap
```

## Available Formulae

| Formula | Description | Version | Install |
| --- | --- | --- | --- |
| [`kpil`](https://github.com/qjoly/kpil) | Spin up a GitHub Copilot CLI container with a read-only (no-secrets) kubeconfig | v0.2.0 | `brew install qjoly/tap/kpil` |
| [`mcp-omni`](https://github.com/qjoly/mcp-omni) | MCP server for Omni Talos cluster management — native gRPC, no omnictl dependency | v0.1.3 | `brew install qjoly/tap/mcp-omni` |
| [`talosctl-oidc`](https://github.com/qjoly/talosctl-oidc) | OIDC certificate exchange server and client for Talos Linux | v0.1.0 | `brew install qjoly/tap/talosctl-oidc` |

## Updating

Formulae are updated automatically every day via GitHub Actions.
To trigger a manual update: **Actions → Update formulae & README → Run workflow**.
